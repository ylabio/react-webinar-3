Задача 1

На главной странице для каталога создайте постраничную навигацию. На одной странице выводятся максимум 10 записей. 
В запросе на сервер потребуется передавать параметры limit и skip. Примеры запросов в файле /api-examples/articles.http

Дополните функционал возможностью изменения количества выводимых на одной странице наименований, 
например 5, 10 и 20. Дизайн под элемент выбора количества страниц не нарисован, реализуйте самостоятельно. Расположите рядом левее от нумерации страниц. 


Задача 2

При клике по товару переходить на страницу с подробным описанием товара. Переход должен работать с главной страницы и из корзины. 
Сведения о товаре нужно подгрузить через API, зная id товра. Для перехода на страницу товара примените библиотеку react-router https://reactrouter.com 
Пример выборки товара по id есть в файле /api-examples/articles.http. 
В дизайне в верхней части “Главная” - это пока единственный пункт меню для перехода на главную (можно добавить подчеркивание при ховере).

# HW-2 — Компоненты (Y-Lab React Webinar 3)

##  Цель
На второй лекции основное внимание было уделено **декомпозиции компонентов**, **структурированию проекта** и **разделению логики и представления**. Мы реализовали полноценную корзину, подключили каталог товаров и организовали все компоненты по отдельным папкам. Задание строго проверялось и принималось один раз.

Проект развивался на основе ветки `lecture-2`, форкнутой из [ylabio/react-webinar-3](https://github.com/ylabio/react-webinar-3).

---

##  Что сделано

###  Задача 1: Каталог и корзина
- Список записей стал **каталогом товаров** с ценами.
- Кнопка "Добавить" помещает товар в корзину. Количество накапливается.
- В шапке отображается **общее количество уникальных товаров** и **сумма**.
- Добавлена **модалка корзины**:
  - Показывает все добавленные товары с их количеством.
  - Кнопка "Удалить" удаляет весь товар из корзины.
  - Внизу отображается **итоговая сумма**.
- Кнопка закрытия — в шапке модального окна.
- **Удалены** все элементы из первой лекции: выделение, счётчики, добавление записей.

###  Задача 2: Отказ от `defaultProps`
- Реализована передача значений по умолчанию без `defaultProps`.
- Используются стандартные значения параметров функции или логика `value || fallback`.

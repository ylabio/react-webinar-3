
Задача 1﻿

Доработать выделение записей. По умолчанию должна выделяться только одна запись, поэтому при выделении одной записи выделение с других записей должно сбрасываться. Клик по уже выделенной записи снимает её выделение. Клики, связанные с другими действиями (например, добавление или удаление), не должны влиять на текущее выделение. Если при клике на запись дополнительно удерживать клавишу Ctrl (или Cmd на macOS), то выделение других записей не должно сбрасываться, что должно позволять выделить множество записей.



Задача 2

Доработать создание новой записи. В текущей реализации код для новой записи формируется на основе размера массива, что не гарантирует уникальности кода после удаления записей. Необходимо реализовать генерацию уникальных числовых кодов. Достаточно обеспечить неповторяемость кодов в рамках сессии. Если удалить последнюю запись с кодом 7, то при добавлении новой записи её код должен быть равен 8. Использованные коды не должны повторяться. На макете отображается уникальный код записи, а не порядковый номер.



Задача 3

Вывести количество совершенных выделений для каждой записи фразой “Выделяли N раз”. По умолчанию у всех ноль. Фразу с нулём выводить не надо.
